# The product

Read this for orientation. It only covers what's safe to publish, so read `.knowledge/` for the full rules: see `/confluence-updated`.

## What UltraStream is

A video and live-streaming app for adults (18+), on iOS and Android. Viewers watch videos, shorts and live streams, and reward the creators they like with real money. Creators keep 97% of every reward.

## People

- **Viewer:** every account starts here. Needs an account and a passed age check before seeing any content, so there's no guest browsing.
- **Creator:** a viewer who has opened a channel. It's the same account and login, with a public channel added on top.
- **Admin:** staff using the admin panel.

A person with a channel has two identities. The channel's name and handle appear on the channel's own content. Everywhere else, such as commenting, following or rewarding, they act with their personal handle.

## Content

- There are three content types: **video**, **short** (vertical) and **live recording**. There are no text or image posts.
- Videos appear in Discover. Shorts appear in Discover and in the Shorts feed.
- A file can't be replaced after upload, only its details. There are no drafts.
- Uploads can be published now or scheduled.
- Filters use one fixed category list.

## Main tabs

**Discover**, **My Feed** (followed creators), **Create**, **Shorts** and **Profile**. Creators reach **Ultra Studio** from Create or the Profile tab.

## Words to use

Use one term for one thing, and match the app:

| Say | Don't say |
|---|---|
| Reward | Tip, donation, gift |
| Handle (personal @name) | Username, unless matching a current screen |
| Channel | Page, profile (for a creator's public presence) |
| Content item, or video, short, live recording | Post, unless quoting a brief |
| Ultra Studio | Dashboard, creator studio |

## Screens with no reference

Figma has no admin side. Admin screens here use the shared components, but their layout is a proposal unless someone supplies a reference from the current panel. Say this when handing over admin work.

## Figma versus the live app

- A few Figma screens differ from production. Product rules in Confluence win.
- Some Figma upload and edit screens show an 18+ question or toggle. It isn't in the current app, so use the versions without it.
- The Figma "Wireframes" page is an old concept and isn't current. Never use it.
